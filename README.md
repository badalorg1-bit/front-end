# بينا — MVP (React + Supabase)

منصة تأجير وبيع ومقايضة. هذه النسخة تستخدم **Supabase** (Postgres + Auth + Storage) بدل البيانات التجريبية في الذاكرة.

> الأسعار تُخزَّن كأعداد صحيحة بالجنيه المصري (بدون كسور). الدفع يتم داخل المنصة (محفظة + ضمان)؛ الشحن والتسليم الفيزيائي خارج النطاق.

## التقنيات

| الطبقة | الاختيار |
|---|---|
| الإطار | React 19 + TypeScript |
| البناء | Vite 7 |

## إعداد Supabase

بدون مفاتيح، تظهر حالات «غير مهيأ» ولا تُختلق بيانات اتصال.

1. أنشئ مشروعًا في [supabase.com](https://supabase.com).
2. في **SQL Editor** شغّل المهاجرات بالترتيب الرقمي من `supabase/migrations/` (من `0001_init_schema.sql` حتى `0021_bayna_rebrand.sql`):
   - `0001_init_schema.sql` — الجداول، المحفزات، RLS، قيد تداخل الإيجار
   - `0002_storage.sql` — بنكك `listing-images` وسياسات الرفع
   - والبقية: الإدارة، الدفع والضمان، المحفظة، المراجعات، الرسائل، الإشعارات، الاشتراكات، شحن الرصيد، إعادة التسمية إلى «بينا»
3. من **Project Settings → API** انسخ Project URL و anon key.
4. أنشئ `.env.local` (يُتجاهل من git — لا تضع المفاتيح في `.env.example` أو أي ملف متتبَّع):

```powershell
Copy-Item .env.example .env.local
# ثم عدّل القيم داخل .env.local
```

```text
VITE_SUPABASE_URL=https://YOUR_PROJECT.supabase.co
VITE_SUPABASE_ANON_KEY=YOUR_ANON_KEY
```

5. أعد تشغيل `npm run dev`.
6. في **Authentication → Providers → Email** اختر ما يناسبك:
   - **Confirm email** مفعّل ⇒ سيُطلب تأكيد البريد قبل الدخول
   - **Confirm email** معطّل ⇒ التسجيل يفعّل الحساب فورًا للتجربة المحلية

### حدود الصور

- حتى 6 صور للإعلان، كل صورة ≤ 5MB
- الأنواع: JPEG / PNG / WebP / GIF
- الرفع في بنكك `listing-images` تحت مجلد باسم معرّف المستخدم — سياسة RLS تمنع رفع مجلد غيرك

## النطاق (MVP)

**مدعوم:**

- تسجيل/دخول/خروج عبر Supabase Auth + ملف `profiles` وملف عام `/u/:id`
- نشر إعلان: إيجار أو بيع أو مقايضة + صور + تحقق على الخادم/الـ RLS
- بحث وفلترة على الإعلانات المنشورة
- طلب تأجير (تواريخ) أو شراء أو مقايضة (إعلان مقابل) — ودورة الحياة: قبول / رفض / إلغاء / إكمال / فتح نزاع
- الدفع داخل المنصة: دفع مباشر أو ضمان (حجز المبلغ في المحفظة ثم تحويله بعد الإتمام) + شحن رصيد بإشعارات
- المراجعات بين المستخدمين
- الرسائل المباشرة بين المستخدمين + دردشة المساعد «بينا»
- الاشتراكات والباقات (للمستخدمين والتجار)
- لوحة إدارة بالأدوار (`super_admin` / `admin` / `moderator`) مع مؤشرات KPI وسجل تدقيق وتنبيهات ذكاء اصطناعي
- إشعارات تلقائية عبر محفزات قاعدة البيانات

**خارج النطاق (لا تُزيَّف):**

- تحقق برقم الهاتف (OTP)
- الشحن والتسليم الفيزيائي للبضائع (يُتفق عليه خارج المنصة)

## حدود تقنية

- التأمين والأسعار أعداد صحيحة بالجنيه المصري
- تداخل تواريخ الإيجار المقبولة يُمنع بقيد EXCLUDE في Postgres
- RLS مفعّل على كل الجداول العامة؛ الرفع مقيّد بمجلد المستخدم
- `.env.local` غير متتبَّع — المفاتيح في المتصفح هي anon فقط
